# Harshit Goswami — AI/ML Portfolio Website

A modern, responsive, and visually immersive personal portfolio website built for showcasing AI/ML projects, research experience, technical skills, and developer activity.

This portfolio combines futuristic cyberpunk/glassmorphism UI design with interactive animations, project showcases, research achievements, and responsive layouts to establish a strong professional presence online.

## Features

- **Modern Futuristic UI/UX**: Dark mode aesthetic with cyber cyan and purple accents, glassmorphism cards, and radial glow effects.
- **Interactive Hero Section**: 3D hexagon avatar frame with floating animation, animated typing tagline, and quick CTA links.
- **AI/ML Project Showcase**: Interactive project cards with dynamic category filtering (Deep Learning, Machine Learning, NLP, Computer Vision, Web/Deployed).
- **Interactive Case Study Modals**: Detailed popups highlighting the problem statement, technical approach, model architecture, and measurable results.
- **Dynamic Skills & Progress Bars**: Animated expertise indicators triggered on scroll via Intersection Observer.
- **Interactive AI Assistant Demo (Expandable)**: Built-in knowledge base with mock AI responses for quick visitor inquiries.
- **Contact Form & Social Links**: One-click links for Email, Phone, GitHub, and LinkedIn, plus an integrated message form.
- **Fully Responsive**: Optimized layout for desktop, tablets, and mobile devices.
- **Zero Heavy Dependencies**: Built with pure HTML5, CSS3, and Vanilla JavaScript for ultra-fast load times.

---

## Tech Stack

### Core Frontend
- **HTML5**: Semantic and SEO-optimized markup.
- **CSS3**: Custom properties (CSS variables), Flexbox, CSS Grid, Glassmorphism, and keyframe animations.
- **JavaScript (ES6+)**: Vanilla JS for DOM manipulation, typing effects, modals, and observer animations.

## Deployment

The repository includes a GitHub Actions workflow (`.github/workflows/new_static.yml`) configured to automatically publish static content directly to **GitHub Pages** on every push to the `main` branch.
